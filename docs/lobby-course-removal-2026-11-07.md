# ロビーのコースと旧配布物の削除

削除前の版は GitHub の `4b0840010708db1474e1f7a8c6c19f7b7a840118` に保存されています。

## 削除したもの

- カートの SKY・SPACE・ORBIT 全コース、車両・ガレージ・乗降・走行・ジャンプ・レース表示。
- ホストのレース同期タイマー、開始要求、コース切替、コース座標の圧縮・復元、親画面の開始ボタン。
- ロビーのアスレチック、段階的な足場生成・当たり判定・カメラ補正、およびビルド時に再挿入する処理。
- カート入口の案内・扉。元の出口は周囲と同じ壁に戻し、移動判定も閉じています。
- 公開フォルダーの `gas-2026-10-23` と `gas-2026-10-26`。過去のGAS用HTML・TXT・DOCX・閲覧ページなど14ファイル、計14,344,190バイト。

サッカー・少林サッカー・鬼ごっこ・消える床・撮影・ガチャ・衣装・プレイヤーの保存データは削除していません。
旧コースにいた本人が再接続したときだけ、古い乗車状態を解除してロビーの安全な床へ戻します。プレイヤーのチケットや所持衣装は維持します。旧クライアントとの混在を考慮し、古い乗車状態を識別する条件と解除処理は残しています。

## 手元の同条件ビルドによる比較

| 対象 | 変更前 | 変更後 |
| --- | ---: | ---: |
| 公開出力の非圧縮合計 | 36,164,177 B | 21,585,132 B |
| ロビーの編集用HTML | 915,915 B | 803,875 B |
| ロビーHTMLのgzipサイズ | 281,153 B | 245,178 B |

公開容量は約14.58MB（40.3%）削減。旧配布物の削除は配布容量の削減であり、プレイ中のFPS改善率を表すものではありません。コースの3Dモデル生成とレース同期タイマーを廃止したため、それらの初期準備・常時処理もなくなります。

## 確認方法

- `node tools/check-lobby-course-removal.mjs`: 旧コースからの再接続、所持品維持、旧操作の拒否、全入口の組み込みデータ、旧配布物の除去。
- `node tools/check-lobby-live-poses.mjs`: 位置・ジャンプの同期、遅れた更新、衣装や名前の維持、旧乗車情報の拒否。
- `node tools/check-lobby-shared-scenes.cjs`: 実際の3D画面でコース・足場・車両・操作表示がないこと、出口の閉鎖、サッカー、移動と写真撮影。
- `node tools/check-phone-runtime.cjs`: 隔離した部屋データでアプリの起動・ロビー・会議・マップ・役職一覧・タスク操作。
- `node tools/check-lobby-solo-host.cjs`: 残した3種類のゲーム開始と終了、ホスト権限、スマホ操作。
- 少林サッカー・追加技・自動ツイン・ホスト／ゲスト同期の既存チェック。
- `npm run build`。
