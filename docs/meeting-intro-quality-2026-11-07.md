# 会議開始アニメーションの改善

作業場所: `/workspace/game-interaction-continued-2026-11-07`。
専用コピー内の変更。未公開。

## 変更

- 緊急会議は暖色、死体通報は赤系の光を使い分ける。金属の円形デッキ、発光ライン、支柱、柔らかい接地影で奥行きを作る。
- 緊急ボタンに上面・縁・固定ボルトを追加。腕の振り上げ、手とボタンの接触、押し込み、衝撃波、照明、衝撃音のタイミングを合わせる。
- 通報は駆け寄り・急停止・驚き・指差しの流れ。縦画面では発見後にカメラが寄る。発見マークの「!」が細くつぶれる問題も修正。
- 見出し・通報理由・進行表示を整理。旧スタイルの表示順・背景・画面全体の揺れと競合しないよう演出中だけ切り替える。
- 既存の約3秒のタイムラインと人物情報を使い、その後の死亡者紹介へつなぐ。演出からゲーム状態の変更や通信は行わない。
- 発光は材質と少数の照明で実現し、影の追加描画やポスト処理は使わない。床の32部品は1描画にまとめる。
- 動きを減らす設定ではカメラ移動・反動・飛び散る粒子を抑える。途中参加で衝撃音を遅れて鳴らさない。非表示でフレームが止まっても終了時刻に後片付けする。

## 確認方法

- `node tools/check-meeting-intro-preload.cjs`: 30/60/120Hzで同じ手の軌跡、接触と押し込み、1回だけの衝撃音イベント、25回再生後のGPU資源数、途中参加、低モーション、フレーム停止時の終了処理。
- `node tools/check-meeting-intro-visual.cjs`: スマホ横・縦・PCサイズで演出の構図を撮影。
- `node tools/check-built-meeting-intro.cjs`: 別の確認用ビルドへローカル専用の呼出し口を挿入し、実際のキャラ生成・ページCSS・会議開始処理を確認。練習用のローカルDBを使用し、本番への通信を遮断。緊急会議／通報を844×390、390×844、1366×768で確認。
- `npm run build`: 公開用の通常ビルドには確認用の呼出し口を含めない。
