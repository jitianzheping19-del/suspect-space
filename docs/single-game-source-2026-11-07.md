本体の正本は `index.html` です。旧URL用のHTMLを3つコピーしてGit管理していたため、同じ変更を含む約10MBの差分が繰り返し保存されていました。

| Git管理する本体HTML | 変更前 | 変更後 |
| --- | ---: | ---: |
| ファイル数 | 4 | 1 |
| 行数の合計 | 122,404 | 30,601 |
| バイト数の合計 | 13,328,372 | 3,332,093 |

重複3ファイル分の91,803行、9,996,279バイト（75%）を除去しています。この数字は本体HTML4ファイルの比較で、リポジトリ全体の行数や実行速度の改善率ではありません。単一の本体HTMLに含まれるゲーム処理や機能は変更していません。

## 編集・ビルド・出力

- 本体は `index.html`、ロビーは引き続き `assets-source/lobby-lounge.html` を編集します。
- 衣装・ロビー・会議・描画設定・Airshipの生成ツールは正本だけを更新します。
- `npm run build` の各生成処理が終わった後、`tools/sync-game-entrypoints.mjs` が互換HTML3つを再生成します。これらはGit管理せず、古いローカルツールやブラウザ検証用に残します。必要ならこのスクリプトを単独で実行して再生成できます。
- GAS・DOCX・各プレビューの出力ツールは `index.html` を直接読みます。互換HTMLがない状態でも出力できます。
- GitHub Pagesには引き続き本体1つと旧URL向けの転送ページを配信します。旧URLのクエリ・ハッシュ・PWAの識別子を維持します。
