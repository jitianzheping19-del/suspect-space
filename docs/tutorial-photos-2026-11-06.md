# チュートリアルの画像表示

フットサルのチュートリアル動画を再生できない場合、実際の操作動画から切り出した3枚の画像へ自動で切り替えます。全20項目に60枚のJPEGを同梱しました。

- 再生非対応、再生拒否、動画の読み込みエラー、6秒間の読み込み停止を検出。
- 「写真で見る」で手動切り替え。「動画を再試行」で再び動画へ戻せます。
- 写真表示中は別の操作を選んでも写真表示を継続します。
- ダッシュの4秒スタミナ、トラップ中の方向指定の説明も更新しました。
- タッチ直後にボタンが入れ替わっても二重入力されないようにし、再試行の直後に写真へ戻る問題を修正。
- 閉じる・サッカーから退出する場合は動画と待機タイマーを終了。以前の動画の遅れたエラーで現在の表示を切り替えません。

検証は `tools/check-soccer-tutorial-photos.cjs`（スマホ縦・横、PC）と既存の `tools/check-soccer-tutorial.cjs` で実施。画像の欠落時にも操作説明が残り、Pagesのサブパスでも動画と写真を読み込みます。

画像の再生成: `node tools/render-soccer-tutorial-photos.mjs`。元動画から取得するため、モデルを再描画する必要はありません。

公開には、本サイド会話のサッカー修正、ゴールデンスキン10種類と本変更を含めています。現行Firebaseのルールを両プロジェクトから取得して照合し、新スキン追加のためのサーバー側ルール変更は不要と確認しました。リポジトリ内のルール定義には新IDを登録済みです。
