10種類すべてを既存のゴールデンレジェンドレア（レアリティ5）に登録。課金ガチャの金枠は合計48種類、全課金スキンは98種類になります。金枠の提供割合は既存の20%を使用し、未所持を優先する既存仕様を維持しています。

`premium-golden-skins.js` にモデル・アニメーションを実装。`tools/sync-premium-catalog.mjs` で `gacha-catalog.js` と `database.rules.json` の所持・プロフィール・ルーム内衣装の許可を同期しました。既存カタログの全項目と番号が一致し、新規10項目だけ増えていることを基準コミット `0f7267a` と比較済みです。

検証:

- `node tools/check-golden-additions.mjs`: 新規10種類の抽選対象、20%の確率、カタログと保存ルールの整合、スマホ・PCの3Dモデル、アニメーション、描画負荷、二重破棄の防止。
- `node tools/check-golden-additions-visual.cjs`: 実際のプレビューで10種類を選択し、試合／ロビー、歩行／ジャンプ、繰り返しの着替え後のメモリ、動きを減らす設定をスマホ・PCで確認。
- `node tools/check-realtime-gacha.mjs` と `node tools/check-costume-ownership.mjs`: ローカルの保存処理テストと既存所持品の維持を確認。外部データベースへの書き込みは行っていません。
- `npm run build`: 埋め込み衣装ライブラリ・ロビーテンプレート・公開用ファイルを再生成。

一覧画像: `verification/golden-additions/collection.png`。個別画像・描画統計も同じフォルダにあります。

累積の `source.patch` にサッカー修正と本追加を収録しています。取り込み後はビルドで埋め込みHTMLを再生成してください。公開時には現行ルールを照合し、新IDに対応することを確認してください。今回の現行サーバーはID別の制限を持たないため、ルールの変更は不要でした。
