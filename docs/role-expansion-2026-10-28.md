# 役職・会議・再接続の追加実装

作業場所：`/workspace/artifacts/side-role-implementation-2026-10-28/source`。
独立したコピーで実装・検証し、既存の編集内容を保持した差分を `/workspace/github-deploy` に反映しました。公開操作は行っていません。

## 実装した仕様

| 役職 | 主な能力 |
| --- | --- |
| オーバーローダー | 正体を全員に公開し、移動速度・キル範囲を強化、キルクールを半減。3秒後から解除可能。会議で解除。 |
| クラッカー | 近くの死体を通報不能にする。会議開始時に全死体を消去。 |
| ミッショナリー | 対象を宣教し、設定時間後に自決させる。宣教師の死亡後も継続。最後の相手がクルーか無害な第三陣営なら勝利。 |
| ボディーガード | 対象に護衛を付け、通常キル時に身代わりになる。護衛は会議をまたぐ。 |
| サンドワーム | ベント内から強襲。キル待ちはベント内か停電中だけ進む。通常キルで待ちが増え、強襲・停電中のキルで短くなる。 |
| イーター | 死体を食べるか、接触を維持して生存者を丸呑み。丸呑みは防御を貫通し死体を残さない。既定3人または最後の無害な相手との生存で勝利。 |
| フリーザー | 使用者を含む生存者全員を5秒停止。クライアントの移動・操作とホストのコマンド検証に適用。対象と秒数はこの会話で確認済み。 |
| マッドてるてる | 投票追放で人狼陣営が勝利。必要タスクと人狼認識は設定可能。個人タスクは全体タスクに加算しない。 |
| ジャッカルのサイドキック | 近くの1人を味方へ変更。作成直後はキル不可。生存ジャッカルが全員死亡した後に昇格しキル可能。再勧誘は既定で不可、設定で変更可能。陣営の人数判定にも含める。 |

- 妖狐は人狼の攻撃を防ぎ、1.8秒の3Dシールドと画面演出を本人・攻撃者の両方に表示。他プレイヤーには表示しない。
- 切断者のタスクを総数から外し、復帰で同じ割当と進捗を戻す。
- 死亡時、3個以上の担当タスクを2個に削減。完了済みを優先して保持。タスクバー上の数字を削除。
- 会議中の一時切断では通常の15秒猶予を超えて席を保持。復帰時はチャットへ一度だけ通知。明示的な退出や会議終了後の離脱処理を継続。
- 切断中に死亡した人は、再接続しても死亡状態を維持する。天秤による会議ID変更も考慮。
- 過去の確認済み死亡者と、今回初めて判明した死亡者を死亡時刻で区別。
- 今回の死亡者を、実際の所持スキン入りのThree.js製の墓と名前で横並びに表示。狭い画面では横スクロール。死亡者なしの場合は「死亡者なし」で自動的に次へ進む。
- 表示のために作ったモデル・テクスチャ・WebGL描画領域は終了時に解放。スキンの縮尺計算には非表示のパーティクル保管領域を含めない。
- 通常のホスト専用ゲーム状態書込みを使用し、今回の機能用のFirebaseサーバー追加は不要。
- `npm run build` の先頭で、ホーム画面から開くHTMLと別名の入口を `index.html` に同期。

## 調査元と実装の範囲

最初の6役職の主要能力は [ExtremeRoles公式説明](https://github.com/yukieiji/ExtremeRoles.Docs/tree/main/docs/追加役職) を参照。
[マッドてるてる](https://wiki.supernewroles.com/ja/Roles/Crewmate/MadRole/マッドてるてる) と [ジャッカル](https://wiki.supernewroles.com/ja/Roles/Neutral/ジャッカル) はSuperNewRoles公式説明・公開ソースを参照。
取得した本文は、この作業ディレクトリの親に `role-research.json`、`additional-role-research.json`、`jackal-research.json` として保存。

既存ゲームに合わせた主要能力の実装です。元MODの全オプション互換ではありません。ミッショナリーの任意の会議投票能力「神の宣告」、ボディーガードの任意の会議中ガード・殉職告知などは含みません。
サンドワームの強襲でも、今回指定された妖狐のシールドは維持します。

## 追加補完

- 部屋設定に「バイタル」「監視カメラ」のオン・オフを追加。保存・共有・再読込に対応し、オフの端末は3D表示・接近操作・直接呼び出しから利用できない。
- 停電開始時に修理済みの回路を1個増やし、修理が必要な個数を従来より1個減らす。
- 会議下部の投票確認UIを画面端まで伸ばさず、最大430pxの枠へ変更。
- 切断中に実際に殺された人も、今回の死亡者として墓へ表示する。切断だけによる離脱とは区別する。
- ユーザー確認により「眷属」はヴァンパイアの眷属として実装。既存ヴァンパイアに1回限りの眷属作成ボタンを追加。眷属は元役職の能力・タスクを失い、人狼陣営として通常キルを使える。親の死亡・追放では後追いする。双方のキルにクールダウン連動を追加。
- 眷属は初期配布の役職に追加しない。作成・キルクールダウン・ベント可否を設定できる。
- 参照元：[SuperNewRoles Vampire.cs](https://github.com/SuperNewRoles/SuperNewRoles/blob/master/SuperNewRoles/Roles/Impostor/Vampire.cs)、[VampireDependent.cs](https://github.com/SuperNewRoles/SuperNewRoles/blob/master/SuperNewRoles/Roles/Impostor/VampireDependent.cs)。元MODの任意オプションすべての互換実装ではない。
