# 隠し少林サッカーモード

独立した作業コピー `/workspace/soccer-shaolin-controls-2026-11-07` に全機能と専用フェイントボタンを実装し、公開用の独立したチェックアウトへ統合。元の作業ディレクトリのコード・Git状態は変更していません。
ベース: `/workspace/soccer-secret-mode-2026-11-07`（元ベースは `/workspace/soccer-ui-controls-2026-11-07` の `93002c9`）。

## 発動

ホストが青・赤のフィールドBOTを両方0人にし、0人になってからマイナスを3回押します。得点板の開始表示が「隠しモード READY」に変化。その部屋の次のサッカー1試合にだけ有効です。
試合開始時に予約を消費し、得点後の再開では効果を継続。終了・中止・参加者不足で解除されます。別の部屋や次の試合へ引き継ぎません。カウントと予約は部屋の共有状態に保存します。

## 操作と効果

| 操作・条件 | 効果 |
| --- | --- |
| カーブシュート | 回転による曲がりを5倍にし、回転の減衰も弱める |
| フェイント | 横移動6倍。最大5体の残像が240msで消える。左右への分身演出付き |
| 上部の「分身フェイント」 | 1回タップで即座にダブルタッチ。移動入力が左なら左へかわす。シュートの長押し・タップ待ち・ハンドの連打待ちを解除し、技が二重に出ることを防ぐ |
| 通常移動・ダッシュ | 基本の移動倍率3.2倍。ボール所持時やダッシュ倍率と組み合わせる |
| フライパス | 飛行時間3.6秒、頂点は約16m |
| 高い球の近くでシュート | 天空ジャンプシュート。キャラクターと接触判定を同じ予測位置に合わせる |
| ボール所持中に右下のフェイント3連打 | 手で持つ。もう一度3連打で下ろす。キックでも放せる |
| 最大までためたシュート | 炎の尾を引く。キーパーに当たると後方へ押し込み、ボールは進む |
| 「太極拳」 | 0.9秒間、近くの飛来球を反射。回転を残してゴールへ返す |
| 「鉄頭」 | 浮き球へジャンプしてヘディング。着地で衝撃波 |
| 「腹砲」 | 所持球を腹の位置で0.85秒ためて発射 |
| 「空中リレー」 | 近くの味方へ高いパス。空中でも中継でき、連続した後の天空シュートは炎属性 |
| キーパーの自動技 | 試合開始11秒後から27秒おきに、片側のグローブが1.8秒間巨大化。反対側は通常サイズ |
| ゴール引っ越し | 開始18秒後から22秒おきに片方のゴールが横へ2.4m移動し、6秒で元へ戻る。表示・ポスト・得点判定・キーパー位置を同期 |
| 「雷鳴シュート」 | 0.45秒のためから高速の低い球。稲妻と金色の軌跡 |
| 「流星シュート」 | 0.85秒ため、高い弧を描いてゴールへ落とす。炎と周回する岩片、地面への着弾で衝撃波 |
| 「旋風奪取」 | 近くの相手やこぼれ球を0.35秒後に奪う。高さ1.5m未満・距離2.8m未満。逃げた球や味方の所持球は奪わない |
| 「氷晶壁」 | 正面に5本の氷結晶。0.3秒後から相手の球を一度弾き、砕ける。実際の結晶の形に沿った高速球の接触判定付き |
| 「双龍パス」 | 0.5秒ため、味方へ浮き球を送る。2頭の龍と尾が球の周囲を旋回。空中リレーにつながる |
| 「ドライブシュート」 | 0.55秒ため、縦回転で途中から沈むシュート。距離に応じて打ち出す高さを調整 |
| 浮き球へ味方2人が近づく | 低めの球には自動ツインシュート。2人が同じ接触点に合わせ、一度だけ強い球を放つ |
| 頭上・後方の浮き球へ味方2人が近づく | 自動ツインオーバーヘッド。2人が空中で体を倒し、左右の足を合わせて蹴る |

必殺技のボタンは隠し試合の参加者だけに表示。太極拳・鉄頭・腹砲は5秒、空中リレーは1秒の再使用待ちがあります。条件がそろわないボタンは無効になります。
専用フェイントも既存の再使用待ちを守ります。「基本技」「奥義」「連携」の3ページに分け、各操作のタッチ領域を44px以上確保しています。「連携」ではドライブのボタンと、自動ツイン技2種類の条件を表示します。

ツイン技は0.4秒後の球の位置を予測し、同じチームの2人が各1.8m以内、互いに2.5m以内にいると自動で準備します。2人とも着地して操作可能な状態が必要です。技の途中で味方が離れる、ボールが奪われるなど条件が変わると中止。発動後は各6.5秒待ち、連続で空中拘束しません。通常モードでは発動しません。
雷鳴・旋風は5.5秒、流星・氷晶壁は6.5秒、双龍は4秒、ドライブは5秒の再使用待ちがあります。

## 演出・操作画面の改善

- 11個の操作ボタンを専用アイコンと色で区別。発動可能、発動中、回復中を表示し、円形ゲージで再使用までの進み具合を示します。自動ツイン技は別の2枚の説明カードに表示します。
- 条件不足の場合は「浮き球を待つ」「ボールが必要」「足元に戻す」などの理由を表示します。
- 技名の表示は共有された発動記録に合わせます。同じ状態の再受信で繰り返し表示されません。空中リレーは連携数も表示します。
- 画面の狭い横向き端末では、カメラ・説明・移動・シュートのボタンを避ける位置へ切り替えます。キーボード操作と動きを減らす設定にも対応します。
- 炎の軌跡を2枚の滑らかなリボン、発光する芯、火の粉で描画。空中リレーの球は青い軌跡になります。
- 太極拳は逆方向に回る輪と光球、腹砲は収束する輪、鉄頭はジャンプに追従する光と着地の3重の波、動くゴールは足元の輪で表現します。
- 新技にはため姿勢と振り抜き、稲妻、流星の岩片、立体的な旋風、光を反射する氷結晶、角と目を持つ双龍を用意。ツイン技は両選手に同時の光輪と接触時の粒子を出します。
- 演出は既存の当たり判定や試合時間を変えません。軌跡は最大32点、描画用の形状と材質を再利用し、試合終了時には演出を片付けます。

## 通常の練習の修正

ゴールラインを横切る瞬間だけでなく、球が完全にゴール内に入った状態も確認し、得点と再開を一度だけ実施します。ネットの側面・屋根・背面からの侵入は衝突で防止。ゴール裏に残った無効な球は1.5秒で得点を増やさず戻します。キーパーが所持している球は対象外です。
