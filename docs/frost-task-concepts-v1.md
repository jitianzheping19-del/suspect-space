# フロスト：通常タスク22種類

承認された22種類をプレビューとゲーム本体へ配置。11部屋に2個ずつ、操作の違う3D機械として実装する。
通常タスクのシミュレーションは `frost-task-rules.js`、描画と入力は `frost-task-machine.js`。
プレビュー上部の「タスクを選ぶ」から全種類を直接操作できる。

| 部屋 | タスク | 操作と完了条件 |
| --- | --- | --- |
| 中央ドーム | 基地回線を復旧 | 回路タイルを回転し、制御室から3つの区画へ電力を通す。不要な枝はつながない。 |
| 中央ドーム | 基準時計を同期 | 速度の違う3つの時計を、それぞれ基準の目盛りで止める。タイミングを合わせる操作。 |
| 格納庫 | 貨物の重心を調整 | 重さの違う貨物を台の上へ動かし、傾きを水平にする。重さは外見だけでは分からない。 |
| 格納庫 | ドローンを着陸誘導 | 小さな操作パッドで横風を受ける機体を誘導し、着陸枠内で速度を落として止める。 |
| 観測室 | 星図を照合 | 参考星図と向きの違う観測画面から、同じ星座の星を選んで結ぶ。 |
| 観測室 | 望遠鏡の霜を除去 | レンズをなぞって霜を落とす。こすると透明になり、必要な視野が確保されれば完了。 |
| 通信室 | 救難信号を測位 | 3本のアンテナの指向線を動かし、強度表示を頼りに発信源の位置を割り出す。 |
| 通信室 | 欠損した信号を復元 | 途切れた波形の断片を正しい順に並べ、端と端が連続する通信データに戻す。音は不要。 |
| 医療室 | 採血ラインを固定 | チューブをガイドに沿わせ、折れ曲がりを避けながら固定具へ順に押し込む。 |
| 医療室 | 治療薬を調合 | ピペットを押す時間で液量を調節し、指定した比率の薬液を作る。入れすぎた分は吸い戻せる。 |
| 居住区 | 温室の散水を管理 | 乾き方の違う3つの苗床を見ながら給水を切り替え、すべてを適正湿度にする。 |
| 居住区 | 放熱フィンを組み直す | 折り畳まれた3Dフィンを開閉し、隣とぶつからない順序で放熱器を展開する。 |
| 研究室 | 氷コアの地層を採取 | 深度を合わせて薄い層を切り出す。必要な層だけを残し、上下の氷を混ぜない。 |
| 研究室 | 遠心分離機を安定化 | 揺れる回転軸へ逆方向の補正を入れ、回転が安定するまで中心の範囲に保つ。 |
| 検体室 | 検体を無菌移送 | 密閉トレーを傾けて検体を通路へ運び、汚染部分に触れずに保管容器へ入れる。 |
| 検体室 | 冷凍保管庫を調整 | 加熱・冷却の遅れを見越して操作し、温度を指定範囲内で一定時間維持する。 |
| 電力室 | 過電流の原因を遮断 | 接続図と電流計を見比べ、正常な回線を落とさずに故障した枝だけを切り離す。 |
| 電力室 | 蓄電池を交換 | 端子を安全な順序で外し、固定具を解除して電池を交換。正しい向きで再接続する。 |
| 掘削区 | ドリルの噛み込みを解消 | トルク計を見ながら工具を左右交互に回し、力をかけすぎずに固着を緩める。 |
| 掘削区 | 岩盤の亀裂を封止 | 発泡材を亀裂へ充填する。隙間を残さず、必要量だけを入れて固める。 |
| 地底調査室 | 地中レーダーを走査 | 探査ヘッドを動かして断面をスキャンし、反射の深さから空洞を見つけて印を付ける。 |
| 地底調査室 | 探査ローバーを回収 | ウインチを巻く・緩める操作で張力を保ち、障害物で引っ掛かった機体を回収する。 |

## 共通の作り方

- 全て立体の機械として操作できるようにする。ボタンを押すだけで自動的に終わるタスクは作らない。
- スマホ横向きでも指で操作できる大きさにする。PCでは同じ箇所をマウスで操作する。
- 通常は1個6〜12秒程度。短いものと長いものを部屋間で偏らせない。
- 失敗してもその場でやり直せる。意図を示す光・形・動きを使い、長い説明文と音声は必須にしない。
- 緊急タスクは別の9端末。試合では酸素2端末、停電4回線、冷却炉2人の認証、通信ダイヤルの既存ホスト判定へ接続する。
- 完了時は既存のタスクコマンドでホストが担当・距離・部屋の状態を検証する。閉じると入力と描画を破棄し、再操作は新しいセッションで始める。
