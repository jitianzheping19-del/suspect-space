# 残り15種類の課金衣装の仕上げ（2026-10-28）

対象は streetdj から retroarcade までの15種類。既に改良した先頭5種類と、元の8種類の衣装は対象外。

- 衣装に織り模様、刺繍、金具、反射材、紙の折り目などを追加。衣装の裾をカプセルの下端まで合わせた。
- DJの波形画面、アーケードのゲーム画面、書家の揺れる掛け軸などを追加。背面装備もそれぞれのテーマに合わせて仕上げた。
- ランタン、トレー、筆などの小物を実際の腕に取り付け、歩行・ジャンプ時にも手元を追従するようにした。
- 波紋、墨の筆跡、六角形、デジタル模様など、15種類それぞれに異なる足元のオーラを追加。既存の立体モチーフと併用し、顔の前を覆わない。
- テクスチャは作成時に一度だけ描画。追加の床オーラは1メッシュで、既存の時計・描画ループを共有する。衣装を外すと材質・形状・テクスチャを解放する。
- カスタムシェーダーも幽霊などの透明度変更に追従する。衣装の権限・取得状態・ゲーム能力は変更しない。

主な変更は `premium-couture.js`、`premium-tailored-designs.js`、`premium-tailored-skins.js` と `tools/sync-costume-companions.mjs`。ビルド時にロビーの埋め込みモデルと4種類のゲームHTMLへ同期する。

実際のモデルを使うプレビューは `gift-skins-preview.html?collection=remaining`。待機・歩行・ジャンプ、試合／ロビー、前後の表示とオーラ切替に対応する。

`tools/check-remaining-couture.cjs` は15種類×2体形×PC／スマホの60ケースを確認する。顔の遮蔽、腕・脚への追従、オーラの更新、シェーダーの透明度、形状の数値、切替後のリソース数とブラウザーエラーを対象とする。

実機での発熱・FPS測定は行っていない。本番へのデプロイは行っていない。
