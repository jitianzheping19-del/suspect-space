# 2026-11-08 練習・タスク・ロビーの改善

作業場所: `/workspace/practice-controls-2026-11-08`。元の作業ツリーを変更せず、隔離したコピーで実装。コミット・公開は未実施。

## 変更内容

- 撮影台の段差とジョイスティックの解除処理を修正。
- 練習設備は近づいて「使用」。初回の「！」と点線は、一度開いたらアカウント単位で非表示。
- 練習を「タスク」「役職能力」に分け、マップ→タスク選択で自動ロード。設定画面と配色・操作サイズを統一。
- 役職練習はロード画面付き。右上の「練習の設定」は折りたたみ式。自分への投票は会議時だけ表示。
- 配線のつかめる範囲を拡大。不要な見出し・開始ボタン・案内・偽死体のエラーを整理。
- ディテクティブ、自分用メモ、ペットボタンと表示設定を削除。トラッカーの追跡位置を三角印で表示。
- カメラマンは練習中も写真をライブラリへ保存。
- 停電は全スイッチOFFから開始。視界の範囲は維持して内部を明るくし、ゴーグルを発光。ONにした部屋の人だけ補助照明を強化。
- スケルド全26タスクの割り当てを均等化。試合後も部屋ごとの利用回数を保持し、固定3種類への偏りを解消。
- 過電流・航法時計・シールド蓄電池などの表示・操作を確認。蓄電池は取り出し・差し込み時の位置を確定させ、9段階の手順を表示。
- リアクターは一つの9ボタンパネルで点灯順を記憶して入力。
- アンテナの配置・目標、貨物の重量・位置、中継信号の波形・並びを毎回変更。判定に対応した数値・目印・手順を表示。
- ドアは全体で最大2枚。閉鎖待ち・解錠中も数え、妨害とドアーの能力に同じ制限を適用。
- ロビーの施設ラベルをアイコン・大きな名称・状態の順に統一。0人なら「待機中」。操作盤の単純なボタンには不要な施設説明を付けない。
- 役職モニターを大型化し、15人の名前と役職を2列で表示。フットサル横のソファを3席に変更し、ホスト側の座席定義も一致。
- プールの波・浮き輪・プレイヤーが同じ水面を参照。緩い回転流で移動し、操作を止める画面では流されない。
- カスタマイズを入口から離し、アップデート設備を壁の端へ移動。用途のない機械4台を撤去。
- ステータスを色付きの点と文字で表示。フレンド一覧の「登録済み0人」を削除。フレンドが開いた部屋にはホスト名を表示。
- 部屋設定の不要な括弧・見出し・枠を削除。陣営別の人数を大きく表示。
- 新しい特別チケット10枚のキャンペーンを用意。以前の受取済みアカウントも対象。1アカウント1回、残高と受取記録を同じトランザクションで保存。
- アップデート情報を更新。
