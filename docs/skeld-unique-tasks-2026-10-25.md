# スケルドの通常タスクを重複させない

20地点の通常タスクを、7種類の既存端末と13種類のフロスト端末へ固定割り当てする。各地点のID・座標・完了記録は維持する。

| 地点 | 操作 |
| --- | --- |
| 電気室・配電盤 | 配線接続 |
| ナビ・受電盤 | 過電流の回線を遮断 |
| O2・酸素ライン | チューブ接続 |
| 管理室 | カードスワイプ |
| 医務室 | 身体スキャン |
| リアクター | 回路を回して接続 |
| ウェポン・照準 | 三角測量アンテナ調整 |
| シールド・放熱 | 放熱板展開 |
| ストレージ | 燃料補給 |
| セキュリティ | レーダー走査 |
| 通信室 | アップロード |
| 下部エンジン | 番号入力 |
| 食堂 | 重心調整 |
| 上部エンジン | 出力調整 |
| ナビ・星図 | 星座照合 |
| シールド・中継 | 波形復元 |
| O2・フィルター | 霜除去 |
| ウェポン・整備 | ドローン着陸誘導 |
| ナビ・時計 | 時計同期 |
| シールド・蓄電 | バッテリー交換 |

以前の個別割り当て自体は既に存在していたが、原定義のkindにはuploadやwiresが複数残っていた。今回、操作画面の指定とkindを一致させ、古いID判定へ進む経路も明示的な端末指定を優先するよう変更した。一覧生成時にIDと実際の操作タイプの重複を検出するため、今後同じ操作を二重に割り当てると初期化時に検出できる。

変更: `skeld-tasks.js` とゲームHTML4ファイル。緊急妨害の解除端末は対象外（複数人で復旧する既存仕様）。テスト・ビルド・デプロイは未実施。
