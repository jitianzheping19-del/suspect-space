# ロビー上空アスレチック

ロビー内の「上空アスレ」看板（x=-4,z=10.3）から、30個の足場を飛び移って高さ34の頂上へ登る。操作は既存の移動とジャンプ。落下時のワープや死亡はなく、下の足場またはロビーの床・家具に着地する。中間チェックポイントは設けない。

- 貨物デッキ・グレーチング・パネルの足場と、進行方向の矢印、頂上のトロフィー。
- 床面は水平の矩形、装飾は縁に配置。各足場の上面を既存の床検出に登録。
- 足場は有限の厚さを持ち、上空の足場がロビー床での移動を遮らない。
- 異なる高さにいるプレイヤー同士の水平衝突を除外。
- 床判定・他プレイヤー描画・親画面での位置メッセージ検証の高さ上限を60へ拡張。既存の位置同期を利用し、追加のFirebaseデータや定期通信は導入しない。
- 三人称カメラは高さを含めて追従。俯瞰カメラもプレイヤーの高さを基準に配置。
- 足場の部品と矢印はInstancedMesh。静的なコースで、追加の毎フレーム処理やライトはない。

編集元は `assets-source/lobby-ascent.js`。`tools/sync-lobby-ascent.mjs` がロビーへ埋め込み、既存の `tools/sync-costume-companions.mjs` によりゲーム4ファイルへ梱包する。
