# 前半の改善指定への対応

## 今回変更した箇所

- **操作（4・5・9）**：タッチ開始時のボタン受付を全ボタンへ拡張。マップ表示時のresetInputを削除。スティックのキャプチャが他UIへ移ってもwindowのpointermoveとtouchmoveで保持し、本人の指を離した時に解除する。子iframeへのフォーカス移動での入力解除も抑制。キル移動の更新時は入力を保持する。会議・死亡・勝利時など強制停止が必要な経路は残す。
- **ホスト（3）**：交代処理の待機時間を60秒へ変更。既存の接続確認・候補選定・Firebaseトランザクションを使用する。
- **待機時の消費電力（13・17）**：ロビーで20秒、入力・ジャンプ・車両・乗員の移動がない時のみ描画を15FPSにする。移動入力と位置同期は60Hzの別ゲート。操作や周囲の移動で通常描画へ戻る。
- **通話（32〜39）**：再接続の片付けでマイクの保存設定を上書きしない。再接続バックオフを短縮。Pannerと明示的な距離ゲインの二重減衰を解消。画面端・距離外縁で連続的に減衰。受話バスにコンプレッサー、音量設定にスピーカー確認と接続・マイク状態確認を追加。
- **会議（41〜45）**：頭の投影位置から名前・役職・投票済みマーク・票数・吹き出しを配置。固定フォントサイズによる長文の早すぎる省略を解除。投票確認を角丸・余白・押せる大きさに整理。
- **能力（46・47・53）**：既存のキャンセル経路を維持し、選択・フォーカス・無効状態の表示を整備。使用ボタンにベント・ドア・会議ボタンの3Dアイコンを追加し、用途に応じて切り替える。
- **レビュー**：初試合終了を端末に保存し、その後の安全な待機時だけ案内。送信成功後はFirebaseと端末の両方で送信済みを記録。星だけ、文章だけでも送信可能。星は固定のタップ領域を持つ一列表示。管理者ホームのメッセージボタンから名前・星・文章の一覧を表示する。
- **管理者**：設定ナビへ管理者タブを追加。メッセージ・部屋管理への入口と、通信/描画の読み取り専用診断を配置。Firebaseの権限確認は維持する。
- **アプリ情報**：更新内容と既読バージョンを2026-10-25へ更新。

## 既存実装を維持した範囲

指定番号1・2・6・7・8・10〜12・14〜16・18〜22・24〜30・36・40・44〜49には、既に以下の処理がある。今回それを置換して二重に実行せず、入力・会議・通話の修正先から引き続き利用している。

- 保存セッション・部屋状態・役職・位置の復元、切断猶予と接続表示。
- 状態別のボタン配置、viewport同期、開始時刻と勝利演出の待機処理。
- スマホ30FPS/PC60FPS、DPR上限、影の間引き、静的モデルの結合・インスタンス化、背景停止、終了時のGPU資源解放。
- 端末の事前ロード、DOMの文字表示と3D解像度の分離。
- WebRTCの補間バッファ・停止サンプル、追従ペット、直結不能時のFirebaseフォールバック。
- 役職等の永続状態と位置情報の保存経路の分離、限定した部屋一覧、直近40件のロビーチャット、古い部屋の整理。
- 個人別音量の端末保存、空き入室位置の選択、投票対象の強調と確定確認。
- 会議能力のキャンセルと対象制限、チャット閲覧位置維持、新着表示。

## 実行していないこと・制限

ユーザー指示によりテスト・ビルド・ブラウザ確認は実行していない。ソース生成のみ実行。各修正の実機での効果、発熱、通信量、名前の重なりは未検証。通信を介するキルや能力はホストの確定処理が必要で、通信遅延をゼロにはできない。

デプロイとFirebaseルールの公開は未実施。文章だけのレビュー（rating=0）は変更後のdatabase.rules.jsonの反映が必要。現行公開ルールでは拒否される場合がある。

診断画面はWebRTCの送受信バイト数とThree.jsの資源数であり、Firebaseの請求ダウンロード量の計測ではない。今回その請求量の機能別集計を実装したものではない。
