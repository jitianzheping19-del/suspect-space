# 配信コードと起動時の読み込みの軽量化

変更前の版は `d86944515f22bf55102349a1bc827d4e31867177` に保存されています。

## 変更内容

- GitHub Pages のゲーム本体を `index.html` の1本に統一。従来の3種類の `space-suspect*.html` は小さな転送ページとして出力します。URLのクエリ・部屋コード・ハッシュを引き継ぎ、同じオリジンの保存データを使用します。
- インストール済みPWAの識別子は維持し、新規起動先をルートURLに変更しました。GAS・DOCX用の編集元となる独立HTMLはリポジトリに残します。
- 起動時の `database.rules.json` の重複取得を廃止。ビルドが同じ内容を埋め込んでいるため、管理者のルール表示にも埋め込みデータを使用します。サーバー上のデータベース権限を変更するものではありません。
- アセットの保存先を一度開いて再利用し、現バージョンに見つからない場合だけ過去バージョンを探します。同時要求をキャッシュ検索の前からまとめ、ストレージが使えない場合はネットワーク取得へ進みます。失敗した要求は再試行できます。

サッカー・少林サッカーなどの機能やユーザーの保存データは変更していません。

## 容量比較

同じローカル環境の `npm run build` の出力を比較しています。

| 対象 | 変更前 | 変更後 |
| --- | ---: | ---: |
| 配信出力の非圧縮合計 | 21,585,132 B | 13,119,638 B |

8,465,494 B（約8.5MB、39.2%）削減しました。主な削減対象は別URL向けに複製されていた本体です。この比率は1回のアクセスの転送量・ロード時間・プレイ中のFPSの改善率ではありません。CIではライセンス付き音声処理モジュールと追加ドキュメントが含まれるため、公開出力の絶対容量は上記と異なります。

## 確認

- `npm run build`
- `node tools/check-game-entrypoints.cjs`: 旧URL3種類とクエリ・ハッシュの引き継ぎ、端末内保存データ、PWAの識別子、重複本体と設定ファイルの出力廃止。
- `node tools/check-built-startup.cjs`: 公開用ビルドのスマホ起動、ログイン画面のタッチ操作、埋め込み設定の表示。アカウント・部屋には接続しません。
- `node tools/check-game-cache-lookups.mjs`: 現バージョンへの48要求で保存先を1回だけ開き、列挙せずに処理。過去版の再利用、同時要求、ストレージ障害、通信再試行、アカウント通信の除外。
- `node tools/check-game-asset-cache.cjs`: 実際のService Workerで再読み込み・オフライン・バージョン更新時のキャッシュ再利用。
- `node tools/check-phone-runtime.cjs`: 隔離したデータでスマホ起動、ロビー準備、会議、マップ、役職一覧、タスク操作。
- `node tools/check-lobby-course-removal.mjs`: 前回削除したコースの復活がなく、残したゲームと所持品が維持されること。
- 埋め込みルールと `database.rules.json` の内容一致、`git diff --check`。
